## Usage Instruction

### 1. Clone repository

```bash
git clone https://github.com/MGT06/e-wallet_frontend.git

cd EWallet
```

### 2. Install dependency

```bash
npm ci
```

### 3. Run Frontend

```bash
npm run dev
```

### Additional command

```bash
# Check lint
npm run lint

# Create a production build in the dist/ directory
npm run build
```
