## Usage Instruction

### 1. Clone repository

```bash
git clone https://github.com/MGT06/e-wallet_frontend.git

cd EWallet
```

### 2. Install dependency

```bash
npm ci
```

### 3. Jalankan Frontend

```bash
npm run dev
```

### Command tambahan

```bash
# Periksa lint
npm run lint

# Buat build production di direktori dist/
npm run build
```
